# Axxes CV Converter

## Description

This is a custom pipeline that uses various NLP type models to parse, classify and rewrite information that would be found in and around the cv of an application in the field of IT. The desired output is a standardised cv, used within Axxes IT consultancy. This entire project is developed by Jonas Vandenberghe, Joppe Iemants and William Plancke under the guidance of the Howest AI lecturer team. However it is the intellectual property of Axxes and the entire codebase will be transfered to them when the project is complete.
